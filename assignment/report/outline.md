## 2. Dataset and classes (~1.5 pages)
320 photographs, 80 existing labels, 4 per label. Source: iNaturalist and Wikimedia
Commons via `tools/collect_fish_samples.py` (read-only). Licences, attribution and
SHA-256 recorded in `SAMPLES FISH/metadata.csv`.

| marine_pelagic_demersal | fully marine open-water/bottom + cartilaginous | 24 | 96 |

## 4. Model and hyperparameters (~1 page)
Pretrained torchvision ResNet-18 (ImageNet-1K), FC replaced by `Linear(512→4)`,
all layers fine-tuned. Input 224×224. Train: RandomResizedCrop, horizontal flip,
ColorJitter, ToTensor, ImageNet normalization. Eval: Resize 256, CenterCrop 224,
normalization. Cross-entropy; AdamW lr=1e-3, weight decay 1e-4; batch 32; up to 30
epochs; early stopping (patience 5, min delta 1e-4) on validation loss with best
checkpoint; fixed seed 1337; CUDA when available.
