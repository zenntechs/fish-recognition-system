            Setup
            
Camera help

          

          
        

        

          

            This app reads the camera through Linux V4L2. Under WSL2 the Windows
            camera has to be attached to WSL before the app can see it.
          

          
Attach the camera in Windows

          
    
            
  1. Open PowerShell as Administrator.
    2. 
            
  2. Run usbipd list.
    3. 
            
  3. Find the Integrated Camera BUSID (for example 4-1).
    4. 
            
  4. Run usbipd attach --wsl --busid 4-1.
    5. 
            
  5. Return here and press Retry.
    6. 
          

          
If the feed is green or frozen

          

            The USB/IP link can corrupt some capture modes. AquaVision checks every
            frame and falls back through 960×540, 640×480, 1080p and YUYV
            automatically. If no mode works, detach and re-attach the camera.
          

          
When finished

          

            Stop the camera in the dashboard, then run
            usbipd detach --busid 4-1 to return the camera to Windows.
          

          
Camera busy

          

            Close Teams, Zoom, Camera, or any other app that may have claimed the
            camera before attaching it to WSL.
